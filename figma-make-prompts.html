Figma Make prompt sequence

Munafasat Prompt Kit

16 prompts, in build order, to regenerate the Munafasat RFP wizard in one Figma Make session — rewritten from the current app, including the new RFP Summary review modal that wasn't in the last version of this kit.

How to use this

  1. One Figma Make session, pasted in order. Start a single Make file and paste prompts 1 → 16 one at a time, waiting for each to finish before sending the next — this is a sequence, not sixteen unrelated sessions. Figma Make itself works best this way: a complete first prompt establishes the design system, and every later prompt can just say "match the existing design system" instead of re-specifying colors and type.
  2. Don't skip Prompt 1. It defines the color/type/spacing tokens and the app shell every other screen sits inside. Everything after it is intentionally shorter because it leans on that foundation.
  3. Prompts 4–11 assume Prompt 3 already exists. Each wizard-step prompt only describes what's inside that step's content card — the stepper rail, footer, and collapse/hover behavior come from Prompt 3.
  4. Prompt 12 is the headline addition. The RFP Summary review modal is the newest piece of the real app and the main reason this kit needed rebuilding — give it its own attention rather than rushing past it.
  5. 16 is marked optional. The standalone AI Assistant page is the lowest-value screen to regenerate; build it last, or skip it if you're short on time.
  6. If a screen comes out wrong, prefer a small precise correction over a re-send of the whole prompt — e.g. "move the Grand Total row's font size up 3px" lands better than repeating the paragraph it came from.
